# Fee and Scope Conversation Prompts

Use these as conversation starters, not mandatory negotiation rules.

## If the requested fee is outside budget
“Thanks for sharing the budget range. We can review which outcomes and deliverables matter most, then propose a smaller scope that fits. Which workstream should remain essential?”

## If the client asks for a discount
“We can revisit the fee alongside the scope, timing, or payment terms. I will outline the trade-offs so we can agree on a workable option.”

## If additional work is requested
“That work is outside the current scope. I can estimate the added effort and timing in a change request before we proceed.”

Do not assert that a price cut proves the original fee was inflated, offer unapproved incentives, or promise revenue outcomes.
