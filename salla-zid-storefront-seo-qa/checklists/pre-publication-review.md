# Storefront page SEO review checklist

- [ ] Scope, date, language, platform, page type, and reviewer recorded.
- [ ] Live URL and public page render checked.
- [ ] Page represents a distinct user need and is complete enough to be useful.
- [ ] Product/category/brand/page facts match approved source data.
- [ ] Search title and description are accurate, page-specific, readable, and consistent with visible content.
- [ ] No unsupported offer, availability, delivery, warranty, location, or performance claim.
- [ ] No keyword repetition or fixed-length formula used as a substitute for clarity.
- [ ] Existing URL left unchanged, or an approved redirect/migration plan is documented.
- [ ] Indexing/crawler controls were not changed without explicit approval.
- [ ] Any structured data is platform-supported and matches visible page content; no custom snippet was pasted without technical review.
- [ ] A representative change was reviewed on the live public render before scaling.
- [ ] Search Console observations are scoped by URL, query, language, and date; no ranking/indexing outcome is promised.
- [ ] Change log, owner, reviewer, rollback, and follow-up date recorded.
