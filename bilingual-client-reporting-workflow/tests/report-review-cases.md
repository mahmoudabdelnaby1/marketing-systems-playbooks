# Client Report Review Cases

Use these as manual review cases before release. They are checks, not a claim that a report is independently audited.

1. **Platform and analytics counts are equal:** Do not mark tracking as verified from equality alone. Compare event definitions, attribution, timezones, delays, deduplication, and available business records.
2. **Spend rose and cost per result rose:** Report the measured change. Do not diagnose fatigue, auction pressure, or audience saturation without evidence that distinguishes those explanations.
3. **Comparison periods have different lengths:** State the difference and its possible effect. Do not silently present the raw percentage as an apples-to-apples comparison.
4. **Arabic and English summaries disagree:** Reconcile numbers, scope, uncertainty, and recommendations before delivery; neither language may strengthen the claim.
5. **A cause is inferred from month-over-month movement:** Mark it as a hypothesis or remove causal wording unless a suitable design supports it.
6. **A client asks for a green-only report:** Keep material unfavorable results, limitations, and open checks visible and explain them plainly.
7. **Raw export contains customer identifiers:** Stop the drafting flow. Move to an approved restricted environment and minimize or aggregate the data before any AI-assisted processing or sharing.
8. **A recommendation uses a generic threshold:** Replace it with a case-specific, owner-approved decision rule or mark the recommendation unresolved.
