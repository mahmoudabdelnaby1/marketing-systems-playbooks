# Arabic RTL Interface Review

Review user tasks rather than assigning an arbitrary score. Confirm document direction, Arabic text mixed with Latin terms and numbers, reading and focus order, labels, validation and recovery, mobile viewport and zoom, and keyboard and touch behavior. Verify every delivery, payment, financing, and return claim against approved policy. Record device, browser, page, steps, screenshot, issue, and owner.

The accompanying CSS is a starter, not a universal theme patch. Test selectors against the actual storefront before deployment.
